# Datorspele2
# Šaha spēles apmācības programma

## Par programmu

Šī programma ir izveidota Python valodā. Tā paredzēta diviem spēlētājiem, kuri var mācīties šaha figūru pārvietošanu uz šaha dēļa. Programmas veidošanā tika izmantoti moduļi, funkcijas ar parametriem un divdimensiju masīvs.

## Kā darbojas programma

Programma izveido 8x8 šaha dēli un attēlo to ekrānā. Spēlētāji pēc kārtas ievada figūras atrašanās vietu un vietu, uz kuru figūru vēlas pārvietot. Programma pārvieto figūru uz norādīto pozīciju.

## Izmantotie Python elementi

* Moduļi
* Funkcijas ar parametriem
* Divdimensiju masīvs
* Cikli
* Lietotāja ievade

## Spēles noteikumi

1. Spēlē piedalās divi spēlētāji.
2. Katrs spēlētājs veic vienu gājienu pēc kārtas.
3. Gājiens tiek ievadīts ar koordinātām.
4. Figūra tiek pārvietota uz izvēlēto vietu.
5. Spēle turpinās, līdz spēlētāji nolemj to beigt.

## Faili

* main.py – galvenā programma
* board.py – šaha dēļa izveide
* chess_functions.py – funkcijas darbam ar šaha dēli

## Secinājumi

Veidojot šo darbu, iemācījos izmantot moduļus, funkcijas ar parametriem un divdimensiju masīvus. Programma palīdz labāk saprast Python programmēšanas pamatus.
